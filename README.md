# 戴文軒 TAI MAN HIN — 煙花攝影作品集

深色高質感的個人攝影展示網站,主題為澳門旅遊塔煙花匯演。
純 HTML / CSS / JavaScript,不需安裝任何東西即可瀏覽。

## 快速開始

- 直接雙擊 `開啟網站.bat`,或用瀏覽器打開 `index.html` 即可。
- (可選)用本機伺服器:在此資料夾執行 `python -m http.server 8000`,再瀏覽 http://localhost:8000/

## 網站功能

| 功能 | 說明 |
| --- | --- |
| 全螢幕首頁 | 澳門旅遊塔煙花大作背景,緩慢縮放動效 |
| 關於我 | 個人簡介與攝影題材 |
| 編輯精選 | 3 張代表作,點擊可放大 |
| 作品集 | 15 張煙花作品,點擊開啟燈箱 |
| 燈箱檢視 | 支援 ← → 鍵切換、Esc 關閉、手機滑動切換 |
| 聯絡資訊 | 點擊電話可直接撥號;微信號旁有「複製」按鈕 |
| 手機版 | 自適應排版與全螢幕選單 |

## 檔案結構

```
個人攝影網站/
├── index.html          # 網站主體
├── 開啟網站.bat         # 雙擊即可開啟網站
├── css/style.css       # 樣式(深色金色高質感主題)
├── js/main.js          # 互動邏輯(燈箱、複製功能、動效)
└── assets/
    ├── hero.jpg        # 首頁大圖
    ├── about.jpg       # 關於我照片
    ├── favicon.svg     # 網站圖示
    ├── photos/         # 大圖(燈箱用,1920px)
    └── thumbs/         # 縮圖(作品集用,900px)
```

## 如何換成自己的照片

1. 準備你的照片(JPG),建議長邊 1920px 以內。
2. 換掉 `assets/photos/` 和 `assets/thumbs/` 裡對應檔名的圖片
   (例如 `fw-01.jpg`、`fw-15.jpg`)即可,檔名不變就不用改 HTML。
3. 想改標題/描述,打開 `index.html` 找到對應的 `<figure>`,修改
   `data-title`(標題)與 `data-desc`(描述)。
